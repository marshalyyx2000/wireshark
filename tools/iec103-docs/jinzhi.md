## 物理 / 传输

- 控制方 = TCP **客户端**，监视方 = TCP **服务端**
- 端口 **TCP 6000**
- 站内双网时 I/S 帧双发双收；U 帧不双发
- 字节顺序 **小端**

## APDU 结构

```
68H | 长度低 | 长度高 | 控制域 (12 或 13 字节) | ASDU
```

- 长度 = 控制域 + ASDU 字节数（**小端 2 字节**），APDU 最大 1024
- 原文：`1024 − 1(启动) − 2(两个长度字节) − 13(控制域) = 1008` → ASDU 最大 1008
- 图中只列出 12 项，但算式表明控制域为 **13** 字节。现场存在两种实现，解析器需自适应。

### 控制域

标准 104 的 4 字节部分（第 1—4 字节）：

| 字节 | I 帧 | S 帧 | U 帧 |
|------|------|------|------|
| 1 | bit0=0, N(S) 低 7 位 | bit0=1 bit1=0 | bit0=1 bit1=1 |
| 2 | N(S) 高 8 位 | 0 | 0 |
| 3 | N(R) 低 8 位 | N(R) 低 8 位 | 0 |
| 4 | N(R) 高 8 位 | N(R) 高 8 位 | 功能位 |

U 帧功能位：`TESTFR`(0x43 act / 0x83 con)、`STOPDT`(0x13 act / 0x23 con)、`STARTDT`(0x07 act / 0x0B con)。
STARTDT 的 U 帧中序列号 N 用于协商监视方向 I 帧的起始 N(S)。

扩展部分：

| 偏移（相对控制域起点） | 内容 |
|---|---|
| 0—3 | 上述标准控制域 |
| 4 | 源厂站地址 |
| 5—6 | 源设备地址（小端 16 位） |
| 7 | 目的厂站地址 |
| 8—9 | 目的设备地址（小端 16 位） |
| 10—11（—12） | 备用 |

### 设备地址

16 位，全站唯一。`0xFFFF` 广播。`0x0000` 保留。
`0xFF00—0xFFFD` 网络设备，`0xFE00—0xFEFF` 站级设备（`0xFEFE/0xFEFF` 为系列配置软件）。
`0x0100—0xFC00` 中低字节为 0 的地址归代理设备。主备方式下最低位用于配对。

## ASDU

标准 6 字节头：`TYP | VSQ | COT | COMADDR | FUN | INF`。

### 扩展 ASDU 正文

**ASDU5 标识**：COL(1) + 制造厂名(8 ASCII) + 装置型号(2) + 主版本(1) + 副版本(1)

**ASDU220 历史数据查询**：事件类型(1) + 开始时间 CP56(7) + 结束时间 CP56(7) + RII(1)
事件类型：1 动作元件 / 2 装置自检 / 3 运行告警 / 4 档位 / 5 软压板 / 6 硬压板 / 7 遥信 / 8 操作信息 / 0xFF 全部。
响应为 ASDU10，COT=0x80（查询中）/ 0x81（查询结束）。

**ASDU221 文件目录召唤/选择/召唤节**：FNAM(2) + SNAM(1) + SCQ(1)
SCQ 低 4 位命令：1 选择文件 / 2 召唤文件 / 3 停止激活文件 / 4 删除文件 / 5 召唤节 / 6 停止激活节 / 7 召唤目录；
高 4 位错误码：0 缺损 / 1 无存储空间 / 2 非期望的通信服务 / 3 非期望的文件名 / 4 非期望的节名。
INF 表示文件类型：0 波形 / 0x10 顺控运行 / 0x20 顺控配置 / 0x30 设备态 / 0x40 联锁配置 / 0x50 液晶配置 / 0x60 装置组态 / 0x70 装置虚状态。

**ASDU222 文件目录响应**：重复条目 { FNAM(2) + FLEN(4) + SOF(1) + FTIM CP56(7) }，条数 = VSQ 低 7 位。
SOF = CP8{STATUS(5) , RES1(1) , FOR(1) , FA(1)}。

**ASDU223 文件准备就绪**：FNAM(2) + SNAM(1) + FLEN(4) + FRQ(1)

**ASDU224 节准备就绪**：FNAM(2) + SNAM(1) + SLEN(4) + SRQ(1)
SRQ bit8：0 节准备好装载 / 1 节未准备好装载。

**ASDU225 段的发送**：FNAM(2) + SNAM(1) + DLEN(2) + 数据(DLEN)

**ASDU226 最后段/末节**：FNAM(2) + LSQ(1)
LSQ：1 不带停止激活的节传输 / 2 带停止激活的节传输 / 3 不带停止激活的段传输 / 4 带停止激活的段传输。

**ASDU227 确认**：报文体内含 AFQ
AFQ 低 4 位：1 文件传输肯定 / 2 文件传输否定 / 3 节传输肯定 / 4 节传输否定；
高 4 位错误码同 SCQ。

**ASDU228 遥控校验命令**：RII(1) + NOG(1) + FADDR(2) + DADDR(2) + GIN(2) + OTP(1)
OTP：1 分 / 2 合。

**ASDU229 遥控校验结果**：同 228 布局；COT 14H 允许 / 15H 闭锁。

**CCH 联锁数据发送**：GIN(2) + LDT(1) + VALUE（LDT 0=1 字节 / 1=2 字节 / 2=4 字节）

**CBH 联锁数据请求**：LQT(1) + { DADDR(2) + GIN(2) }... + RII(1)。LQT：0 联锁数据 / 1 正常数据。
