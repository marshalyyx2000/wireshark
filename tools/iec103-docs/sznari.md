# 深圳南瑞（SZNARI）串口 103

依据：《深圳南瑞 IEC-103 规约说明 Ver 2.00.060901》（SZNARI/ZD-14-07-12-01）公开章节。

## 物理层

支持光纤或 RS-485，异步 **8E1**，9600 / 19200 bit/s 可调。

## 链路层

非平衡传输，控制系统为主站，继保设备为从站，严格 Polling。

- 重复帧超时 50 ms（可调）
- 固定帧 `10H C A CS 16H`，CS = (C + A) mod 256
- 可变帧 `68H L L 68H C A ASDU CS 16H`
- **南瑞装置不支持单字符 E5H**，但主站应具备兼容能力（解析器仍识别 E5H）

### 主站 → 保护设备（控制方向）

`0 | PRM=1 | FCB | FCV | 功能码`

| 功能码 | 帧类型 | 功能 | FCV |
|--------|--------|------|-----|
| 0 | 发送/确认 | 复位通信单元 (CU) | 0 |
| 3 | 发送/确认 | 传送数据（总查询启动、命令报文、读写定值/软压板、读测量值） | 1 |
| 4 | 发送/无回答 | 传送数据（广播校时） | 0 |
| 7 | 发送/确认 | 复位帧计数位 (FCB) | 0 |
| 9 | 请求/响应 | 召唤链路状态 | 0 |
| 10 | 请求/响应 | 召唤 1 级用户数据 | 1 |
| 11 | 请求/响应 | 召唤 2 级用户数据 | 1 |

### 保护设备 → 主站（监视方向）

`0 | PRM=0 | ACD | DFC | 功能码`

| 功能码 | 帧类型 | 功能 |
|--------|--------|------|
| 0 | 确认帧 | 确认 |
| 1 | 确认帧 | 链路忙，未收到报文 |
| 8 | 响应帧 | 以数据响应请求帧 |
| 9 | 响应帧 | 无所召唤的数据 |

DFC 恒为 0（可接受新数据），主站须能处理 DFC=1。

## 应用层（深圳所子集）

| 功能 | ASDU |
|------|------|
| 保护动作事件 | ASDU2 |
| 保护告警信息 | ASDU1 |
| 保护状态信息 | ASDU1 |
| 故障录波 | ASDU23/24/25/26/27/28/29/30/31 |
| 读取定值 | ASDU10 + ASDU21 |
| 修改定值 | ASDU10 |
| 读取测量值 | ASDU10 + ASDU21 |
| 读取软压板（控制字） | ASDU10 + ASDU21 |
| 修改软压板（控制字） | ASDU10 |
| 校时 | ASDU6 |
| 信号复归 | ASDU20 |

初始化流程：复位 CU → 标识 ASDU5 → 总查询 ASDU7 → 事件/状态周期上送；每 5 分钟广播校时，每 30 分钟总召唤。
