# 四方（北京四方 CSC）串口 103

依据：《四方保护与测控装置 103 规约实施细则》（基于 DL/T 667-1999 / idt IEC 60870-5-103），公开正文摘录。

## 物理层

RS-232 / RS-485，异步 **8E1**，9600 bit/s（可选 19200），主从 Polling，装置为从站。

## 链路层

与 DL/T 667 一致：

- 固定帧 `10H C A CS 16H`
- 可变帧 `68H L L 68H C A ASDU CS 16H`
- 单字符 `E5H`（四方装置可实现，主站须兼容）

## 应用层

ASDU 头 6 字节：`TYP | VSQ | COT | COMADDR | FUN | INF`。

### FUN（功能类型）

| FUN | 含义 |
|-----|------|
| 128 | 距离保护 |
| 160 | 过流保护 |
| 176 | 变压器差动保护 |
| 192 | 线路差动保护 |
| 254 | 通用分类功能类型 |
| 255 | 全局功能类型 |

### COT（传送原因）

| COT | 含义 |
|-----|------|
| 1 | 自发（突发） |
| 2 | 循环 |
| 3 | 复位 FCB |
| 4 | 复位 CU |
| 5 | 启动/重新启动 |
| 6 | 电源合上 |
| 7 | 测试模式 |
| 8 | 时间同步 |
| 9 | 总查询（总召唤） |
| 10 | 总查询终止 |
| 11 | 当地操作 |
| 12 | 远方操作 |
| 20 | 命令肯定认可 |
| 21 | 命令否定认可 |
| 31 | 扰动数据传输 |

### 关键信息元素（实施细则 4.2.5）

| 元素 | 定义 |
|------|------|
| RET | UI16，相对时间（ms），短路开始至今 |
| RFA | R32.23，参比因子 |
| RPV | R32.23，额定一次值 |
| RSV | R32.23，额定二次值 |
| RII | UI8，返回信息标识符 |
| SCL | R32.23，短路位置（欧姆） |
| SCN | UI8，扫描序号 |
| SDV | I16，单个扰动值，范围 -1 ~ 1-2^-15 |
| SIN | UI8，附加信息 |
| SOF | BS8，TP/TM/TEST/OTEV/RES |
| TAP | UI16，带标志状态变位位置 |
| TOO | UI8，命令类型（1 选故障 / 2 请求扰动 / 3 中止 / 8 通道请求 / 9 通道中止 / 16 请求带标志状态变位 / 17 中止 / 24 请求扰动表 / 32-40 结束 / 64-69 认可） |
| TOV | UI8，扰动值类型（1 瞬时值） |
| CP32Time2a | 4 字节：ms(2) 分 备1 无效 时 备2 夏时制 |
| CP56Time2a | 7 字节：ms(2) 分 时 日/星期 月 年 |
| NGD | CP8：NO(6) COUNT(1) CONT(1) |
| GIN | CP16：GROUP(1) ENTRY(1) |
| GDD | CP24：DATATYPE DATASIZE NUMBER CONT |
| KOD | UI8，描述类别 |

### 数据类型（GDD DATATYPE）

0 无数据 / 1 OS8ASCII / 2 BS1 / 3 UI / 4 I / 5 UF / 6 F / 7 R32.23 / 8 R64.53 / 9 双点信息 / 10 单点信息 / 11 带瞬变和差错的双点信息 / 23 结构
