# 继保南瑞 以太网 103（本次命名为「南瑞网络103」）

依据：《继保南瑞以太网 IEC103 规约》（9600 / 20150603A，系统状态字更新版）公开章节。

> **命名说明**：仓库中既有 `nari_net_iec103` 的显示名是「南自网络103」，其字段与端口同样落在 TCP 1048 / UDP 1032。经核对公开资料，**TCP 1048 + UDP 1032 的客户机/服务器 + UDP 主站识别模型**明确出自「继保南瑞」文档；国电南自的「以太网 103」文档同样沿用该模型（两者都基于同一套 103 ASDU，厂商差异在 FUN/INF 点表）。本实现新增独立协议名 `nrelectric_net_iec103`（显示名「南瑞网络103」），与 `nari_net_iec103` 并存，避免破坏既有过滤表达式。

## 客户机 / 服务器模型

- 主站（监控/远动）作为 **TCP 服务器**，在 `1048 (418H)` 端口被动侦听
- 子站（保护/测控装置）作为 **TCP 客户端**，主动发起连接
- 应用服务数据单元直接跑在 TCP 流上，**无 APCI、无 68H 帧头**，靠 ASDU 头长度推进

## 辅助 UDP 链路（1032 / 408H）

用于多主站场景下子站动态发现主站 IP，并顺带对时：

- 子站作为 UDP 服务器，在 `1032` 端口被动等待
- 主站作为 UDP 客户端，主动发送广播报文
- 报文长度 **41 字节**

| 字节 | 含义 |
|------|------|
| 0 | `FFH` 表示主站 |
| 1 | `01H` 表示包含对时信息 |
| 2-3 | 毫秒（0~59999，低字节在前） |
| 4 | 分（0~59） |
| 5 | 时（0~23） |
| 6 | 日（低 5 位 1~31）+ 星期（高 3 位 1~7，0 无效） |
| 7 | 月（1~12） |
| 8 | 年（0~99，不含世纪） |
| 9-24 | 主站自由赋值 |
| 25-40 | 填 0 |

示例：`FF 01 00 00 1C 0B 02 01 0E 00 ... 00`

## 应用层

- TYP 1~31 兼容范围
- CON 1~63
- ASDU 公共地址：0~254 站地址，255 广播
- FUN：128 距离保护 / 160 过流保护 / 176 变压器差动 / 192 线路差动 / 254 通用分类 / 255 全局
- INF 见 DL/T 667 表 8~18
