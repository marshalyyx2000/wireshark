# 积成 IES-N103 以太网 103

依据（本机）：
- `D:\研发\各个大厂的103规约文本\积成IES-N103以太网通讯规约说明.doc`（V1.00，2006-12，积成电子）

## 规约结构

```
应用层        IEC 60870-5-103 选出的 ASDU
             APCI
传输接口（用户到 TCP）
TCP/IP                       第 4/3/2/1 层
```

第 5、6 层未用。即：**103 的应用层 + 104 的链路层**。

## 物理 / 传输

- 主站 = **CLIENT**，子站（IED）= **SERVER**
- TCP 端口 **6185**
- 广播命令走 **UDP 6185**
- 字节顺序小端
- 窗口尺寸 1；T1 超时重发一次，再超时关闭 SOCKET 重连（不丢事项）

## APDU 结构

```
68H | 长度(1 字节) | 控制域(4 字节) | ASDU
```

- 长度 = 控制域 + ASDU 字节数，APDU 最大 253，ASDU 最大 **249**
- 控制域 = 标准 IEC 60870-5-104（I / S / U 帧），与金智不同的是**没有扩展源/目的地址**

| 帧 | 字节 1 | 字节 2 | 字节 3 | 字节 4 |
|----|--------|--------|--------|--------|
| I | bit0=0, N(S) 低 7 位 | N(S) 高 8 位 | N(R) 低 8 位 | N(R) 高 8 位 |
| S | bit0=1 bit1=0 | 0 | N(R) 低 8 位 | N(R) 高 8 位 |
| U | bit0=1 bit1=1 功能位 | 0 | 0 | 0 |

U 帧：`STARTDT` 0x07/0x0B、`STOPDT` 0x13/0x23、`TESTFR` 0x43/0x83。

## UDP 广播

采用与 TCP 相同的 APDU 帧格式，但**控制域无意义**（通常填 0）。命令 ASDU 用 103 定义。
示例（校时）：`68 11 00 00 00 00 | 06 08 08 00 FF 00 | CP56Time2a`

## ASDU

标准 6 字节头：`TYP | VSQ | COT | COMADDR | FUN | INF`
COMADDR = 装置地址，0—254 单元地址，255 广播。

### 子站（监视方向）使用的 TYP

| TYP | 名称 |
|-----|------|
| 0AH | 通用分类数据 M_GD_N(T)A_3 |
| 0BH | 通用分类标识 M_GI_N(T)A_3 |
| 17H | 被记录的扰动表 M_LRD_TA_3 |
| 1AH | 扰动数据传输准备就绪 M_RTD_TA_3 |
| 1BH | 通道传输准备就绪 M_RTC_NA_3 |
| 1CH | 带标志状态变位准备就绪 M_RTT_NA_3 |
| 1DH | 传送带标志的状态变位 M_TDT_NA_3 |
| 1EH | 传送扰动值 M_TDN_NA_3 |
| 1FH | 传送结束 M_EOT_NA_3 |

### 主站（控制方向）使用的 TYP

| TYP | 名称 |
|-----|------|
| 06H | 时间同步 C_SYN_TA_3 |
| 0AH | 通用分类数据 C_GD_NA_3 |
| 14H | 一般命令 C_GRC_NA_3 |
| 15H | 通用分类命令 C_GC_NA_3 |
| 18H | 扰动数据传输的命令 C_ODT_NA_3 |
| 19H | 扰动数据传输的认可 C_ADT_NA_3 |

### VSQ

`CP8{数目 UI7[1-7] , SQ BS1[8]}`，SQ=0 表示寻址一个信息体内顺序的信息元素，SQ=1 表示寻址单个/综合信息元素。

### COT（子站）

| 值 | 含义 |
|----|------|
| 1 | 自发（突发） |
| 2 | 循环 |
| 3 | 复位帧计数位 |
| 4 | 复位通讯单元 |
| 5 | 启动/重启动 |
| 6 | 电源合上 |
| 7 | 测试模式 |
| 8 | 时间同步 |
| 11 | 当地操作 |
| 12 | 远方操作 |
| 20 | 命令的肯定认可 |
| 21 | 命令的否定认可 |
| 31 | 扰动数据的传输 |
| **40** | 通用分类写命令的肯定认可 |
| **41** | 通用分类写命令的否定认可 |
| **42** | 对通用分类读命令有效数据响应 |
| **43** | 对通用分类读命令无效数据响应 |
| **44** | 通用分类写确认 |

### COT（主站）

| 值 | 含义 |
|----|------|
| 8 | 时间同步 |
| 20 | 一般命令 |
| **40** | 通用分类写命令 |
| **42** | 通用分类读命令 |

### FUN / INF

- FUN：254 = 通用分类（GEN），255 = 全局（GLB）
- INF：230 = 召唤；其余沿用 DL/T 667 兼容范围
- 通用分类写/读通过 COT 40/42 与 ASDU10/21 组合完成

## 与其它厂商的差异小结

| 项 | 积成 | 金智 | 许继/深圳南瑞 |
|----|------|------|----------------|
| 端口 | TCP/UDP 6185 | TCP 6000 | TCP 2404 |
| 长度 | 1 字节 | 2 字节小端 | 1 字节 |
| 控制域 | 4 字节 | 12/13 字节 | 4 字节 |
| ASDU 头 | 6 字节 | 6 字节 | 8 字节（含 COT 2 字节） |
| 扩展 ASDU | 无 | 220—229、0xCB/0xCC | 无 |
