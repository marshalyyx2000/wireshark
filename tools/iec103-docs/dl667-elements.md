# DL/T 667-1999 信息元素与信息序号摘录

来源：公开《103 规约细则》（DL/T 667-1999 / idt IEC 60870-5-103）正文摘录。

## 4.2.5 信息元素定义

| 缩写 | 名称 | 类型 |
|------|------|------|
| RET | 相对时间 | UI16（ms） |
| RFA | 参比因子 | R32.23 |
| RPV | 额定一次值 | R32.23 |
| RSV | 额定二次值 | R32.23 |
| RII | 返回信息标识符 | UI8 |
| SCL | 短路位置 | R32.23 |
| SCN | 扫描序号 | UI8 |
| SDV | 单个扰动值 | I16（-1 ~ 1-2^-15） |
| SIN | 附加信息 | UI8 |
| SOF | 故障的状态 | BS8（TP/TM/TEST/OTEV/RES） |
| TAP | 带标志状态变位的位置 | UI16 |
| TOO | 命令类型 | UI8 |
| TOV | 扰动值的类型 | UI8 |
| CP32Time2a | 四字节二进制时间 | CP32 |
| CP56Time2a | 七字节二进制时间 | CP56 |
| NGD | 通用分类数据集数目 | CP8（NO 6bit / COUNT 1bit / CONT 1bit） |
| GIN | 通用分类标识序号 | CP16（GROUP / ENTRY） |
| GDD | 通用分类数据描述 | CP24（DATATYPE / DATASIZE / NUMBER / CONT） |
| KOD | 描述类别 | UI8 |
