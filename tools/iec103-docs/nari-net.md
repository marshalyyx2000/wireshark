# 国电南自 网络 103

依据：《国电南自 103 网络规约（修改版）》《国电南自以太网 103 规约 2011 版》公开摘要。

## 两种链路传输方式

**方式 1（标准 103 传输）**

- 适用一主多从：多点星形 / 环形 / 共线，也适用点对点
- 窗口尺寸 1 的非平衡传输
- 帧格式 FT1.2：固定帧 + 可变帧

**方式 2（扩充 103 传输）**

- 适用对等网多主站或单主站
- 允许自发事件与变化数据主动上传
- 链路层采用网络传输规则（含源/目的地址、有效传送标志）
- **以太网采用本方式**
- 帧格式：可变帧长帧格式（仅一种）

## 应用层（两种方式相同）

- 采用 103 规约定义的 ASDU；一个链路规约数据单元内不得包含多于一个 ASDU
- TYP 1~31，CON 1~63
- ASDU 公共地址：0~254 站地址，255 广播
- FUN：128 距离 / 160 过流 / 176 变压器差动 / 192 线路差动 / 254 通用分类 / 255 全局
- INF 见 DL/T 667 表 8~18

## 与「南瑞网络103」的关系

国电南自以太网 103 与继保南瑞以太网 103 都采用 **TCP 1048 + UDP 1032（41 字节主站在线广播）** 的客户机/服务器模型，ASDU 相同，差异主要体现在 FUN/INF 点表与部分扩展 ASDU（如南自的 ASDU17 召唤历史信息、扩展远动测量组）。
