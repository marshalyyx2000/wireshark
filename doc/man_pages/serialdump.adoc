== NAME

serialdump - Capture IEC 60870-5-101 frames from a serial port

== SYNOPSIS

[manarg]
*serialdump*
[ *--help* ]
[ *--version* ]
[ *--extcap-interfaces* ]
[ *--extcap-dlts* ]
[ *--extcap-interface*=<interface> ]
[ *--extcap-config* ]
[ *--capture* ]
[ *--fifo*=<path to file or pipe> ]
[ *--port*=<COM port> ]
[ *--baudrate*=<rate> ]
[ *--databits*=<7|8> ]
[ *--parity*=<none|odd|even> ]
[ *--stopbits*=<1|2> ]
[ *--linkaddrlen*=<1|2> ]
[ *--framing*=<ft12|raw> ]

== DESCRIPTION

*serialdump* is an extcap tool that reads an IEC 60870-5-101 serial link and
hands each frame to the IEC 60870-5-101 dissector. Each record in the capture
holds one complete FT1.2 frame, so the frames can be inspected directly rather
than as arbitrary chunks of bytes.

== OPTIONS

--help::
Print program arguments.

--version::
Print program version.

--extcap-interfaces::
List available interfaces.

--extcap-interface=<interface>::
Use the specified interface. The only interface provided is `serialdump`.

--extcap-dlts::
List available data link types.

--extcap-config::
List the configurable options.

--capture::
Start the capture.

--fifo=<path>::
Write the capture to a file or pipe.

--port=<COM port>::
The serial port to capture from, for example `COM3`.

--baudrate=<rate>::
The line speed in bit/s. The default is 9600.

--databits=<7|8>::
The number of data bits. The default is 8.

--parity=<none|odd|even>::
The parity. IEC 60870-5-101 normally uses even parity, which is the default.

--stopbits=<1|2>::
The number of stop bits. The default is 1.

--linkaddrlen=<1|2>::
The length of the FT1.2 link address field in octets. The default is 1.

--framing=<ft12|raw>::
How incoming bytes are packaged. `ft12` (the default) reassembles complete
IEC 60870-5-101 frames; `raw` emits each read as a single record.

== NOTES

Only Windows serial ports are supported. The field lengths configured under
the IEC 60870-5-101 protocol preferences must match the link; set the link
address length there as well as in this tool's options.
